# Numbr 🦅

Numbr is an interactive mobile math game designed to make learning math fun and engaging. 

## 🦅 Meet the Mascot
Our mascot is **Archie the Eagle**! Archie guides players through various math challenges, cheers them on when they win, and helps them learn from mistakes.

## 🚀 Features
* Dynamic math puzzles and speed challenges.
* High-score tracking to monitor progress.
* Animated feedback from Archie the Eagle.
